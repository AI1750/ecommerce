# 电商平台项目 - 2026-08-08

## 项目初始化
- 基于 Medusa (33k GitHub Stars) 开源电商平台架构模仿实现
- 技术栈：后端 Node.js/TypeScript/Express + SQLite(sql.js)，前端 Next.js 14 + Tailwind CSS
- 数据库使用 sql.js (纯 JS，无原生编译依赖)，封装了类 better-sqlite3 同步 API
